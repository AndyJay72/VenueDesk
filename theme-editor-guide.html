🎨 Theme Editor Guide

Everything you need to customise, rearrange, and export VenueDesk pages — without touching the original source code.

📅 August 2026 ⚡ Vanilla JS · Zero dependencies 🗂 Single HTML file

📂 Opening a File

🔗 Link

The editor works entirely in your browser — no server, no install. Open theme-editor.html directly and then load any VenueDesk page.

  • 1
    Open theme-editor.html in Chrome or Edge (Firefox works but drag-and-drop inside iframes is limited).
  • 2
    Drag & drop any .html file onto the editor window — a full-screen drop zone appears — or click Open File in the header.
  • 3
    The page renders live in the right-hand preview. The left panel immediately populates with all CSS variables found in the file.
  • 4
    Every change you make is non-destructive. The original file on disk is never touched until you click Download.
💡 You can reload the editor at any time without losing changes — the editor state lives in the browser tab, not the disk. However, closing the tab clears everything.

🔡 Font Picker

Swap the page typeface without editing any code. Sits directly below the Presets bar.

  • 1
    Choose a font from the Font dropdown — Inter, Outfit, Poppins, Montserrat, DM Sans, Raleway, and 6 more.
  • 2
    The Google Fonts stylesheet is injected into the preview immediately. The page re-renders with the new typeface.
  • 3
    If the loaded file uses CSS variables for font-family (--font-body, --font-sans, --font-heading, --font-base) those are also updated automatically.
  • 4
    The font link is included in the Download output so the exported file loads the font from Google CDN.
⚠️ Font loading requires an internet connection in the preview. Exported files will also need internet access to fetch the Google Font at runtime.

⚙️ CSS Variables

The Variables panel reads every --custom-property from the file's :root {} and light-mode block, groups them by type, and gives you the right control for each value.

🖌 Colour variables

Rendered as a native colour picker + hex text input. Click the swatch to open the OS colour wheel. You can also type any valid CSS colour directly.

📐 Size variables

Rendered as a drag slider + numeric readout. Ranges are context-aware (e.g. --radius-* caps at 28 px, --sidebar-* goes to 500 px).

🔗 Derived variables

Variables referencing var(), calc(), or gradients are shown read-only — editing them would break the reference chain.

☾ / ☀ Dark · Light tabs

Switch between editing the :root (dark) and the body.light-mode (light) blocks independently. Dimmed rows in Light mode are inherited from dark.

Search: type in the filter box to narrow variables. Matching sections expand automatically; non-matching sections collapse.

Reset: hover any row and click the ↺ reset button to revert that variable to its original file value.

Example — what gets exported

/* Only your changed values are written — not the full variable list */ CSS :root { --primary: #34d399; /* changed */ --primary-hover: #10b981; /* changed */ --bg-page: #050d0a; /* changed */ }

🛠 DOM Actions

Once an element is selected via Inspect mode, four action controls appear below the breadcrumb. These modify the actual page DOM — not just styles — and every mutation is tracked in Undo history.

🗑️ Delete

Removes the selected element and all its children from the DOM. The preview updates immediately without reloading the iframe — scroll position and selection state are preserved.

Press Ctrl+Z to recover — the pre-delete state is saved to history.

📄 Duplicate

Deep-clones the element (cloneNode(true)) and inserts the copy immediately after the original. IDs are not deduped — rename them in Edit Text or via the Element → Custom CSS tab.

✏️ Edit Text

Sets contentEditable on the element. The button turns amber while active. Three ways to save:

  • Enter — saves and exits edit mode
  • Shift+Enter — inserts a line break (stays in edit mode)
  • Escape or click away — exits and saves

➕ Add Element dropdown

Select an element type to insert near the currently selected element. See the Add Element section below for full details.

ℹ️ All actions send a postMessage command to the iframe. The iframe executes the mutation, strips all editor-injected tags, and returns the clean HTML to the parent. The main preview iframe is never reloaded — only the background state variable is updated. Download always exports the current DOM state.

➕ Add Element

Insert a new DOM element near the currently selected one using the Add Element… dropdown in the DOM Actions bar.

  • 1
    Select an element in the preview using Inspect mode. If nothing is selected the dropdown shows a toast error.
  • 2
    Choose an element type from the dropdown — it resets to the placeholder immediately so you can add multiple elements in sequence.
  • 3
    The new element is inserted using intelligent placement: container-type elements (div, section, header, main, aside, footer, article, nav, ul, ol) receive the new element as a child via appendChild. All other types get it as a sibling via el.after().
  • 4
    The new element is auto-selected — the Element CSS panel updates immediately and it is draggable, editable, and deletable without any extra clicks.

Primary Button

Inserts <button class="btn btn-primary">New Button</button> — inherits the page's existing button styles.

Container / Grid Box

Inserts a <div> with padding: 1rem and a dashed border so it's immediately visible, ready to receive child elements.

Image Placeholder

Inserts an <img> sourced from placehold.co/300x200. Replace the src via the Element → Custom CSS tab or Edit Text.

Video Container

Inserts a <video controls> with a dark background and minimum height. Set the src attribute manually after insertion.

Paragraph Text

Inserts <p>New text block. Edit me.</p> with color: inherit. Use Edit Text or drag to position it.

💡 To build a layout from scratch: select an existing container, add a Container / Grid Box (appended as a child), then select that new div and add further elements inside it. Each new element is auto-selected, so you can chain additions without re-clicking.

↕ Drag & Drop

Rearrange any element by dragging it to a new position — no buttons, no cut-paste.

  • 1
    Enable 🔲 Inspect and click an element to select it. The element becomes draggable (shown by an amber outline).
  • 2
    Click and drag the element. It fades to 40% opacity while being dragged.
  • 3
    Hover over a target element — an amber border appears on the top edge (insert before) or bottom edge (insert after) depending on which half of the target you're on.
  • 4
    Release to drop. The element is moved using insertBefore or el.after(). The DOM mutation is sent back to the parent and Undo history is updated.

↩ Undo / Redo

The editor maintains a 50-step history of all changes — CSS edits, DOM mutations, and preset applications.

When history is pushed

  • On file load (initial state)
  • When the iframe confirms a DOM mutation (vd_dom_mutated) — after originalHtml is updated, so the snapshot captures the new state
  • On preset apply and font change
  • 1 second after the last CSS variable or element property change (debounced — avoids a snapshot on every slider tick)

What is snapshotted

  • originalHtml — the full DOM state (includes DOM mutations)
  • overrideDark + overrideLight — CSS variable deltas
  • elemOverrides — per-selector property overrides

Undo restores all three simultaneously and re-renders the preview. After undoing, making a new change discards the forward history (same behaviour as most editors).

⬇ Exporting

Three ways to get your work out of the editor.

⬇ Download HTML

Exports the full modified HTML file with CSS variables baked into :root and the light-mode block, element overrides appended as <style>, and any font link injected. Named filename-themed.html.

⎘ CSS Patch

Exports only the changed variables and element overrides as a standalone .css file. Drop it into any existing project with a <link> tag — nothing else changes.

⎘ Copy CSS

Copies the complete :root {} block, light-mode block, and element override rules to the clipboard. Paste directly into a <style> tag or your CSS file.

CSS Patch example output

/* VenueDesk Theme Patch */ CSS :root { --primary: #34d399; --primary-hover: #10b981; --bg-page: #050d0a; } aside.sidebar { width: 320px; padding: 2.5rem 2rem; }
ℹ️ For production use, the CSS Patch approach is recommended — it keeps the original HTML untouched and the patch can be maintained independently as a versioned file.

Deploying to GitHub Pages

After downloading the themed HTML, replace the target file in the repo and push. GitHub Pages serves from the repo root — remember to sync the CommunityHub/ mirror.

# Replace and sync both copies bash cp ~/Downloads/index-themed.html ./index.html cp index.html CommunityHub/index.html git add index.html CommunityHub/index.html git commit -m "theme: apply emerald preset + Poppins font" git push origin main

⚡ Tips & Common Gotchas

✅ Best browser

Chrome or Edge give the most reliable iframe drag-and-drop. Firefox works for CSS editing but HTML5 drag within sandboxed iframes can be inconsistent.

✅ sessionStorage pages

VenueDesk pages that read sessionStorage (like vp_token) will redirect to login.html in the preview — this is expected. The editor is for styling, not authentication.

✅ Duplicate IDs after clone

Duplicate creates an exact clone including id attributes. If the page JS queries by ID it may behave unexpectedly — rename IDs in Edit Text or via the Element → Custom CSS tab.

✅ Light-mode editing

Switch to ☀ Light mode in the Variables panel before editing the light-mode block. Changes made in Dark mode only touch :root — they won't appear in body.light-mode.

✅ Very complex selectors

The auto-generated CSS selector is depth-capped at 6 levels. For deeply nested elements the selector may not be unique enough — use + Custom to write a more specific one.

✅ Closing the tab

All state lives in the browser tab's JavaScript memory. Closing or refreshing the tab clears everything. Use Download or CSS Patch to save your work before navigating away.

✅ Add Element inside containers

When you add an element with a container selected (div, section, main, etc.), the new element is appended as a child. If you intended it as a sibling, select the container's parent first, or use drag-and-drop to reposition after inserting.

✅ No iframe reload on mutation

Delete, duplicate, drag-and-drop, and Add Element all update the DOM inside the live iframe without reloading it. Scroll position and the selected element state are preserved. Only the Download output and the Split View Modified pane are synced in the background.
